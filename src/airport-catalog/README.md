# Airport catalog

`airports.json` is a compact, local snapshot of OurAirports' worldwide airport data, downloaded on 2026-10-28 from https://davidmegginson.github.io/ourairports-data/airports.csv.

The catalog keeps active airport records with three-letter IATA codes, removes duplicate IATA codes, and prioritizes airports with scheduled service in autocomplete results. It contains 9,053 unique IATA-coded locations; 4,135 are marked as having scheduled service in the source data.

OurAirports releases this data into the public domain and notes that it has no guarantee of accuracy or fitness for use. Source: https://ourairports.com/data/.
